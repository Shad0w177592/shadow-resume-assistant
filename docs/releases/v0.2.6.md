# 影子简历助手 0.2.6

Windows x64 桌面版。下载安装文件 `Shadow-Resume-Assistant-Setup-0.2.6.exe`；GitHub 自动生成的 Source code 文件不是安装包。

## 本次更新

- 增加 DeepSeek 官方 API 配置入口，同时保留 OpenAI 与兼容中转网关配置。
- 修复已勾选、数量设为“不限”的经历可能在生成时被篇幅预算丢弃的问题。
- 支持直接编辑简历栏目大标题、条目标题，并通过 AI 修改标题。
- 支持通过 AI 修改打招呼语，打招呼语按用户确认的上限限制为 142 个字符。
- 改进润色结果检查，避免内容未变化却提示润色完成。

## 安装与使用

1. 先在旧版设置中备份个人资料，然后退出旧版。
2. 下载并运行 Windows 安装包，安装到原安装目录后打开软件。
3. 在设置页确认版本为 0.2.6。新用户需自行配置所选服务商的 API Key。

安装包暂未做代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从本仓库下载，并可使用附件 SHA256SUMS-0.2.6.txt 校验文件。

## 已知限制

- 本软件是本地桌面程序，不是浏览器在线版。
- AI 服务需要联网，并取决于所选服务商的接口可用性、模型权限及余额。API 用量由服务商计费。
- 语音转写需要所配置服务提供兼容的语音接口；文字模型可用不代表语音接口也可用。
- 保留 Word 排版的 PDF 转换依赖本机 Microsoft Word；未安装时软件会提示相应限制。
- 本次自动化测试不等同于对所有第三方网关、真实麦克风和所有 Word 模板的逐一实测。
