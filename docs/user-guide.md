# 影子简历助手 V1 使用指南

## 推荐流程

1. **建立个人资料库**：填写个人信息、工作经历、技能和自我介绍；其他栏目均可选填。也可导入 PDF、Word、TXT 或 Markdown 简历，逐条确认识别结果。照片可添加、更换或移除。
2. **新建目标岗位**：粘贴完整 JD，让 AI 解析职责、硬性要求、加分项和关键词。不同岗位的数据和简历互相隔离。
3. **查看匹配报告**：检查“已有证据、证据不足、缺失”项。AI 只应使用资料库中存在并被选中的事实。
4. **配置简历**：勾选栏目并拖动顺序；个人信息、工作经历、技能、自我介绍默认选中，但仍可调整。对单条经历可选择“不要用于这一份简历”。
5. **生成和修改**：生成后在工作台逐段编辑，或选中一段，用文字/语音告诉 Agent 如何改。修改先显示建议，接受后才替换正文。
6. **保存版本**：小改动只进入当前草稿；点击“保存版本”才形成历史快照。版本可命名、备注、比较、恢复、导出或删除。
7. **导出**：导出前检查事实、联系方式、栏目顺序和分页。可生成 DOCX 与 PDF。
8. **备份**：在设置中定期备份。恢复前程序会先备份当前数据；清除全部数据前也必须先创建备份。

## 排版检查

单页简历应尽量填满页面但不拥挤；两页简历第二页应超过半页。重点检查中文字体、字号、字间距、行间距、方块装饰、照片清晰度以及跨页断行。
