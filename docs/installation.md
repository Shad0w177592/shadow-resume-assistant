# 影子简历助手 V1 安装说明

## 系统要求

- Windows 10 或 Windows 11，64 位；
- 建议至少 4 GB 内存和 500 MB 可用磁盘空间；
- 使用 AI 生成、岗位分析或语音转写时需要联网；
- 第一版安装包未做代码签名，Windows 可能显示“未知发布者”。

## 安装

1. 获取 `影子简历助手 Setup 0.1.5.exe`。旧版本请勿继续使用。安装或覆盖更新前先完全退出正在运行的影子简历助手。
2. 可先用 PowerShell 校验文件：

   ```powershell
   Get-FileHash '.\影子简历助手 Setup 0.1.5.exe' -Algorithm SHA256
   ```

3. 正确 SHA-256 为：

   ```text
   B9AFB273A557CFDAD6BCE4CAA2E119594D0175EA91193FFB6A1C36307916A581
   ```

4. 双击安装包。若 SmartScreen 提示未知发布者，请先核对来源和哈希，再选择“更多信息”继续。
5. 启动后配置模型服务。使用 JUAPI 时选择“Chat Completions”，Base URL 填写 `https://www.juapi.net/v1`，并填写 JUAPI 控制台提供的模型 ID 和令牌。

## 数据位置与卸载

个人资料、岗位、草稿、版本和设置保存在当前 Windows 用户的本地应用数据目录，不上传到影子简历助手自建服务器。卸载程序不会被当作备份工具；卸载前应在“设置 → 数据管理”创建备份，并把备份文件保存到安全位置。

## 更新前建议

先创建完整备份，再安装新版本。第一版没有自动更新功能。
