# V1 已知限制

- 仅支持 Windows 10/11 64 位，安装包暂未签名，也没有自动更新。
- 仅支持一位用户和中文简历。可配置 OpenAI 兼容中转网关，但网关必须支持 Responses API 和严格结构化输出；只兼容 Chat Completions 的网关无法使用。
- 不需要影子简历助手账号或云端数据库，但 AI 和语音功能需要联网并使用用户自己的 API Key。
- 导入支持 PDF、DOCX、TXT、Markdown；扫描图片型 PDF 没有 OCR，复杂表格、文本框和特殊排版可能只提取到部分文字。
- 可以沿用简洁统一模板或参考原简历内容；V1 不保证逐像素复刻任意原 Word 模板。
- Word/PDF 自动排版以一页充分利用、两页第二页超过半页为目标；内容极少或极多时仍应人工检查。
- 自动事实检查可阻止无证据的新增事实，但无法替代用户核实。用户选择“继续编造”前会收到风险提示，最终责任由用户承担。
- 语音识别结果受麦克风、口音、环境噪声和网络影响，应先检查转写文字再执行修改。
- 备份是未加密本地文件，不包含 API Key。
- V1 不读取项目目录、README 或代码仓库，不提供账号登录、在线协作、云同步、模拟面试或招聘投递。
