## 4. 已确认的技术边界

- FastAPI 仅绑定 `127.0.0.1`，使用操作系统分配的临时端口；
- Electron 每次启动生成一次性会话令牌，前端只能通过受控 preload 调用；
- API Key 不写入 SQLite、日志、备份或安装配置；
- 文档导入先生成 `ParsedDocument`，AI 归类结果必须等待用户确认；
- 简历预览、Word 和 PDF 使用同一 `ResumeDocument`；
- 每条 AI 生成段落必须包含非空 `source_entry_ids`；
- 公司、职位、学校、时间、数字和技术名词由确定性检查守门；
- 一页内容填充与两页第二页占比属于导出阻断检查，不能靠缩小到不可读字号规避。

## 5. 纸张与模板基线

- A4 竖版，210 × 297 mm；
- 中文主字体 Microsoft YaHei，正式安装包提供 Noto Sans SC 回退；
- 单栏正文 9.2–9.6 pt，双栏正文 8.8–9.2 pt；
- 单栏页边距 12 mm 上下、13 mm 左右；
- 双栏页边距 12 mm 上下、13 mm 左右，左栏 53 mm，栏间距 6 mm；
- 一页有效内容高度目标 88%–96%；两页第二页有效内容高度必须超过 50%。

## 6. 外部环境验收说明

以下项目无法仅靠当前开发机自动证明，必须在发布候选阶段由真实环境补充证据：

- Windows 10 真实麦克风录制；
- 使用用户自己的 OpenAI API Key 进行一次真实转写和结构化输出；
- 两台未安装 Python/Node 的干净 Windows 测试机安装、覆盖安装、卸载和重装；

自动化测试不得把这些外部验收伪装成已通过；发布报告必须区分“自动化通过”和“需要真实设备执行”。

## 7. 已知限制

- 扫描 PDF V1 只识别为扫描件，不提供 OCR；
- 双栏模板可能被部分 ATS 错误解析，招聘网站上传默认推荐单栏；
- 未签名安装包可能显示“未知发布者”；
- 语音功能依赖麦克风权限、网络和转写供应商可用性；文字输入始终可用。
