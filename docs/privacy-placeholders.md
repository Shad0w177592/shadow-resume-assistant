# 隐私字段与本地占位符清单 V1

AI 请求发送前在本地替换以下信息，模型返回后只在本地恢复：

| 类型 | 占位符格式 | 是否允许进入日志 | 是否进入备份 |
|---|---|---|---|
| 中文/英文姓名 | `[[PERSON_NAME_1]]` | 否 | 资料本身进入；映射表不进入 |
| 手机号 | `[[PHONE_1]]` | 否 | 资料本身进入；Credential 不进入 |
| 邮箱 | `[[EMAIL_1]]` | 否 | 资料本身进入 |
| 身份证号 | `[[NATIONAL_ID_1]]` | 否 | 默认不建议保存；如用户保存则进入资料备份 |
| 精确住址 | `[[ADDRESS_1]]` | 否 | 仅用户明确保存时进入 |
| 照片 | 不发送二进制；使用 `[[PHOTO_1]]` | 否 | 原照片进入备份 |
| 自定义敏感字段 | `[[CUSTOM_SENSITIVE_N]]` | 否 | 按用户本地资料处理 |
| API Key | 不进入任何模型上下文 | 否 | 否 |

占位符必须满足：稳定、唯一、不可与用户原文冲突、可完整回填、导出前零残留。
