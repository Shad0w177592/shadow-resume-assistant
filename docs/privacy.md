# 隐私说明

影子简历助手 V1 是单机桌面应用，不提供账号、云数据库或团队共享服务。

## 本地保存

以下内容默认保存在本机：个人资料、照片、教育/工作/项目等经历、岗位 JD、匹配报告、简历草稿、手动保存的历史版本、导入文件副本和设置。OpenAI API Key 使用 Windows 凭据管理器保存，不写入 SQLite 数据库、简历导出文件或数据备份。

## 会发送到模型服务商的内容

只有在用户主动执行岗位分析、简历生成或 AI 修改时，应用才调用配置的 AI 服务。请求会包含完成该操作所需的岗位信息、经历证据和当前简历片段。程序会尽量遮盖手机号、邮箱和身份证号，但自动脱敏不能保证识别所有敏感信息；发送前仍应由用户检查。

若配置第三方 Base URL，API Key 和上述请求内容将发送给该中转网关，而不是直接发送到 OpenAI 官方地址。使用前应自行核实网关的运营方、隐私政策、日志保留和安全性。Base URL 作为普通本地设置保存并可能进入备份；API Key 仍只保存在 Windows 凭据管理器中。

语音输入需要在线转写。录音仅用于本次转写流程，应用不把录音作为简历历史版本长期保存。

## 用户控制

- 经历可标记为“不要用于这一份简历”；
- AI 结果在保存或导出前可编辑；
- 备份、恢复和清除全部数据由用户主动触发；
- 清除前要求先备份，并进行二次确认。

备份文件可能包含完整个人信息且当前未加密。用户应自行妥善保管，不要通过不可信渠道传输。
