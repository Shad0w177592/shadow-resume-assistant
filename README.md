# 影子简历助手

一款本地优先的 AI 简历生成与修改工具。

导入已有简历、粘贴目标岗位要求，让 AI 帮你调整经历表达、专业技能、自我介绍及 BOSS 直聘打招呼语。

## 主要功能

- **个人资料库**：管理教育、工作、实习、项目、技能等资料。
- **岗位定向修改**：根据岗位要求优化简历，支持选择需要 AI 修改的栏目。
- **简历工作台**：编辑栏目标题和正文，调整栏目顺序及使用条数。
- **AI 修改与润色**：输入修改要求，对选中的内容进行调整。
- **打招呼语**：生成、编辑和复制用于 BOSS 直聘的打招呼语。
- **文档导入与导出**：支持 Word、PDF 相关处理流程。
- **本地数据管理**：支持备份、恢复与更改数据保存位置。

## 下载与安装

前往 [最新版本下载页](https://github.com/Shad0w177592/shadow-resume-assistant/releases/latest)，
在 Assets 中下载 `.exe` 安装包。

目前提供 Windows x64 版本。

升级前，建议先在软件设置中备份资料并退出旧版，再安装新版。

> 安装包暂未签名，Windows 可能提示“未知发布者”。
> 请仅从本仓库的 Releases 页面下载安装包。
> GitHub 自动提供的 Source code 压缩包是源码，不是安装包。

## 开始使用

1. 在设置中配置 AI 服务。
2. 导入简历或填写个人资料。
3. 添加目标岗位及岗位要求。
4. 进入简历工作台，选择使用的栏目和允许 AI 修改的范围。
5. 生成简历，检查内容后保存或导出。

## AI 服务

支持配置 DeepSeek、OpenAI，以及兼容的 API 中转网关。

需要用户自行提供对应服务商的 API Key。
不同服务商支持的模型、接口及收费规则可能不同。

语音转写需要服务商支持对应的语音接口，
文字对话可用不代表语音转写一定可用。

## 数据与隐私

个人资料和简历草稿主要保存在本机，支持备份与恢复。

使用在线 AI 功能时，完成任务所需的资料和岗位信息
会发送到你配置的 AI 服务商或中转网关。

请勿在 GitHub Issue、截图或公开文件中泄露 API Key、
联系方式及其他个人敏感信息。

## 使用提醒

- AI 生成的内容需要人工核对，尤其是经历、技能和量化成果。
- 复杂 Word 模板的导入与导出效果可能存在差异。
- 保留 Word 排版的 PDF 转换依赖本机 Microsoft Word。
- 本项目仍在持续完善，欢迎反馈问题。
